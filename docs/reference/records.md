# The crew's records: a reference

Generated by `crew reference` from the code (crew#449). Don't edit it by hand.

**Records join by ids, never by time or prose.** Every record carries the context
below where it applies. A run's records, model calls and span share its `run`;
a tick's share its `tick` and `commit`.

## The context every record carries

| Key | Meaning |
|---|---|
| `tick` | The tick's id, unique across commands. Exported as `service.instance.id` too. |
| `commit` | The crew's commit that ran it. Exported as `service.version` too. |
| `dirty` | Whether the crew's tree had uncommitted changes. |
| `pass` | Which pass of the tick. |
| `phase` | The phase of the pass: refine, deliver, land and so on. |
| `run` | One role's work on one card in one phase. Its records share this id. |
| `role` | The role whose run it is. |
| `card` | The card the work is for. |
| `repo` | The card's repository. |
| `sprint` | The sprint it was in. |
| `attempt` | Which attempt at the card. |
| `for` | What the work was for, where there's no card: a retro, a review of a PR. |
| `trace_id` | The trace it was written in: a log line, an event and a span join on it. |
| `span_id` | The span it was written in. |

## Kinds of failure (`failure_kind`)

What happened to the work. "Failed" alone reads as a model call failing, and
usually wasn't one (crew#550).

| Kind | Meaning |
|---|---|
| `call_failed` | The model call didn't return: a connection, a timeout, a server error. |
| `cut_off` | The model answered, and its answer was cut off at the output limit. |
| `empty` | The model answered nothing, typically after thinking (#312). |
| `form_refused` | The model answered, and the crew's form refused the answer. |
| `edit_not_applied` | An accepted answer's edit couldn't be applied to the files. |
| `guard_refused` | A guard refused the change: the regression guard, a protected path. |
| `tests_failed` | The change was applied, and lint or tests failed. |
| `gate_returned` | A gate sent the work back: review, QA, or the criteria check. |
| `undecided` | The role asked a question or decided nothing. |

## The rules that decide (`rule`)

Which of the crew's own rules decided a disposition, a block, a return or a hold.
The record's summary says it for a person; the rule is what a count reads.

| Rule | Meaning |
|---|---|
| `delivery.conflict_with_main` | The branch conflicts with main: resolving it is for a person. |
| `delivery.record_unreadable` | The project's record can't be read, so its rules are unknown. |
| `delivery.open_pull_request` | A pull request is still open on the branch; re-delivering would overwrite it. |
| `delivery.push_failed` | The work was done, and the branch couldn't be pushed. |
| `delivery.workspace_unready` | The story's workspace container didn't start, or its setup failed (crew#778). |
| `delivery.round_trips_no_epic` | The gates kept returning it, and it has no epic to be split again: for a person. |
| `delivery.route_failed` | Where a session's ending sends the story couldn't be settled: blocked for a person. |
| `delivery.pull_request_failed` | The branch was pushed, and its pull request couldn't be opened. |
| `gate.ci_before_review` | CI failed on the pull request's head: back to the Developer with its log, unreviewed. |
| `gate.review_changes_requested` | The Code Reviewer or DevOps Engineer requested changes. |
| `gate.qa_unproven` | QA found criteria the work doesn't prove. |
| `gate.criteria_cannot_all_pass` | A split's criteria contradict each other or a merged test. |
| `story.gate_round_trips` | The gates kept returning it. |
| `story.pinned_tests` | It keeps breaking merged tests it didn't write. |
| `story.review_conflicts_with_criterion` | The review asks for what a criterion forbids. |
| `story.session_blocked` | Its Developer session ended blocked on a missing file or fact, or was stopped. |
| `story.contract_ruling` | At `done`, the Business Analyst ruled it shouldn't change the merged tests it changed. |
| `session.choice` | Its session ended blocked on a choice no one has made: for the Sponsor. |
| `session.no_epic` | Its session ended blocked, and it has no epic to be split again: for a person. |
| `hold.sibling` | It waits for an earlier story in the same epic. |
| `hold.builds_on` | It waits for a story it builds on. |
| `hold.wip_limit` | The next column is at its limit. |
| `hold.no_session` | A role's Task waits for the milestone that brings its role's session. |
