# 9. Ideas live in Discussions

- **Date:** 2026-09-26
- **Status:** Accepted

## Context

Future project ideas needed a home where a tick can't pick one up as work. The
Sponsor didn't want a new mechanism: "I don't want to invent new things with
this."

## Decision

Ideas are posted in the crew repo's GitHub Discussions, in the built-in
**Ideas** category. An idea that's ready becomes a Goal on the board.

## Consequences

- There's no ideas file and no idea label.
- The backlog holds only work that's been decided.
