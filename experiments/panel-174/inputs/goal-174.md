The tool reports on what it's handed and forgets it. It should run as a service: something a user runs as a container from a released image, that keeps the history it's given and answers questions about it. A user sends it what happens as it happens: work started, blocked, finished, escalated. They ask it for any sprint, range or trend without re-sending the past.

What it's sent is as much a contract as what it returns. The format it accepts is versioned and documented the same way as its answers, and a release never changes what an existing version accepts.

It fits into how its users already watch their systems. Its metrics can be scraped, and its logs and traces go wherever the user's other services send theirs.
